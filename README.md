# Discord Invite Replica

Crie uma página web estática que reproduza com máxima fidelidade visual a interface de um convite de servidor do Discord.

Objetivo: Criar uma página de convite fictícia, extremamente semelhante à experiência visual de convite do Discord, mas sem integração com a plataforma ou backend.

Informações do servidor

Nome: iGNISPR

Membros totais: 12.356

Membros online: 2.302

Plataforma visual de referência: Discord.

Design e interface

Reproduza a identidade visual do Discord, incluindo sua paleta de cores, tipografia, espaçamentos, bordas e elementos característicos.

Utilize o tema escuro oficial do Discord.

Crie um card centralizado contendo as informações do servidor.

Inclua um espaço para o ícone/avatar do servidor.

Exiba o nome iGNISPR em destaque.

Exiba a quantidade de membros totais e membros ativos.

Adicione um botão visual de "Aceitar convite".

Inclua elementos visuais semelhantes aos encontrados na tela original de convites do Discord.

Desenvolva uma interface responsiva para desktop e dispositivos móveis.

Requisitos técnicos

Utilize React e Tailwind CSS.

Não implemente backend, banco de dados ou autenticação.

Não utilize APIs externas.

Todos os elementos devem ser puramente visuais.

O botão não deve realizar nenhuma conexão real com o Discord.

Utilize componentes bem organizados e código limpo.

Fidelidade visual

A prioridade absoluta é a semelhança visual com a tela oficial de convite do Discord. Evite criar um design genérico de landing page. O resultado deve parecer uma reprodução cuidadosa da interface de convite, mantendo os elementos visuais, proporções e hierarquia da experiência original.

Importante: Identifique discretamente a página como uma demonstração fictícia, sem apresentar o convite como um link oficial do Discord.
